# UI/UX Pro Max Skill (`uipro`)

Created by NextLevelBuilder (`https://github.com/nextlevelbuilder/ui-ux-pro-max-skill`, `https://uupm.cc`), UI/UX Pro Max embeds design intelligence directly into Claude Code, Windsurf, Cursor, Codex, and Antigravity.

---

## Capabilities & Design Database

- **80 UI Styles:** Neo-Brutalism, Glassmorphism, Bricolage, Swiss Minimalist, Cyberpunk, Apple Fluid, Skeuomorphic Modern, Industrial Bento.
- **192 Harmonious Color Palettes:** Semantic tokens configured for dark/light contrast ratios (WCAG AAA compliant).
- **74 Font Pairings:** Curated Google & system font combinations matching specific industry verticals (Fintech, Developer Tools, Luxury, SaaS, E-commerce).
- **120 UX Guidelines:** Error states, empty states, micro-copy, skeleton loaders, touch targets, and accessibility audits.
- **22 Supported Tech Stacks:** Next.js, React, Tailwind CSS, shadcn/ui, Vue, SvelteKit, Flutter, React Native, Vite.

---

## Installation & CLI Setup

```bash
# Install UI UX Pro Max in Claude Code
Install this skill https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

# Initialize via CLI
npx ui-ux-pro-max-cli init --ai antigravity
# Or for Claude Code:
uipro init --ai claude
```

When designing a new page:

Apply UI/UX Pro Max guidelines:
